# 🚀 RentEase Platform

RentEase is a full-stack web application designed to simplify the process of renting properties. It allows users to browse, list, and manage rental properties efficiently with a clean and user-friendly interface.

---

## 📌 Features

* 🔐 User Authentication (Login/Signup)
* 🏠 Browse Rental Properties
* ➕ Add / Manage Property Listings
* 📱 Responsive UI (Mobile Friendly)
* ⚡ Fast and Interactive Frontend
* 🔗 RESTful API Integration

---

## 🛠️ Tech Stack

### Frontend:

* HTML
* CSS
* JavaScript
* React.js

### Backend:

* Node.js
* Express.js

### Database:

* MongoDB

---

## 📂 Project Structure

RentEase-Platform

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/Aminkhan12631/RentEase-Platform.git
```

### 2️⃣ Navigate to project folder

```
cd RentEase-Platform
```

### 3️⃣ Setup Backend

```
cd server
node install
node server.js
```

### 4️⃣ Setup Frontend

```
cd client
npm install
npm start
```
